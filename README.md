# Gemma 4 Local OCR Preprocessing Demo

This example demonstrates how to approach a local OCR solution, mimicking the use of Gemma 4. It focuses on a key preprocessing step (binarization) to enhance image quality for text extraction, a technique mentioned in the article for cost-effective local OCR. The Gemma 4 inference itself is simulated to keep the example self-contained and runnable without heavy model dependencies.

## Language

`python`

## How to Run

1. Install the Pillow library: `pip install Pillow`
2. Run the script: `python main.py`
